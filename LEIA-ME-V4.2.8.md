# Reino de Aethra v4.2.8

Expansão de campanha com regras de queda e ressurreição, árvores de habilidades exclusivas para as oito classes e comércio/forja compartilhados com aprovação do mestre.

## Para instalar
1. Faça backup de cada campanha.
2. Execute `supabase-migration-v4.2.8.sql` uma vez no Dashboard → SQL Editor do Supabase.
3. Publique `index.html`, `app.js`, `styles.css` e `assets/js/aethra-dice-3d.js` pelo GitHub.
4. Preserve `config.js`, `assets/maps/` e as demais imagens/configurações existentes.
5. Recarregue o site com Ctrl + F5.

Não é necessário Node.js. Leia `GUIA-DE-ATUALIZACAO-V4.2.8.md` antes de publicar.
